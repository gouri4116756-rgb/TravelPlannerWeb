# WanderWise - Tourist Guide Website

## 📖 Overview
WanderWise is a web-based tourist guide application that helps travelers discover popular destinations, attractions, hotels, restaurants, and travel recommendations. The platform provides users with an easy way to explore places and plan their trips efficiently.

## ✨ Features
- 🗺️ Explore tourist destinations
- 📍 View location details and attractions
- 🏨 Find nearby hotels and accommodations
- 🍴 Discover restaurants and local food spots
- 📸 Destination images and descriptions
- 🔍 Search destinations quickly
- 📱 Responsive design for mobile and desktop

- CSS3

- Bootstrap
